Translation layer

Read descriptions and expanded documents in Chinese or English without changing names, source files or model input.

Updated · 2026-10-06Host baseline · 0.2.0-rc.2

The ADR owns provider order and cache identity. The reading and lifecycle note owns document modes, language independence and cancellation. This page does not report a test run or a live latency measurement.

01Language and display

The interface dictionary selects zh or en. The translation switch independently controls display and new work. Chinese defaults to on and English to off. A stored choice takes priority until the user restores the default.

English can translate Chinese when explicitly enabled. Preferences that do not start with en, including an absent preference, use the plugin's Chinese dictionary and target.

02Provider order

The first provider that returns a valid batch supplies the result. Free endpoints precede the configured model.

No user key. Deadline: 3 seconds.

No user key. Deadline: 15 seconds.
Third
Default model
Configured model route
Uses the operator's quota. Deadline: 30 seconds.
Fallback
Authored text
Not a provider
Remains readable when no translation is available.

A failed provider is skipped until translation is re-enabled, the cache is reset, or the process restarts. Cancellation does not trip a provider or start another fallback. Public endpoints provide no availability or latency guarantee.

No parser or translation provider is added to the browser bundle. No host code is modified.

04On-demand reads

A panel or menu read can request description translation. Expanding a document mounts its reader and starts its translation read. Unexpanded files are not pretranslated.

Direct detail reads report unfinished descriptions through translationPending. The client re-reads until it reaches zero, translation is disabled, or the detail closes.

An open slash menu performs up to 40 follow-up reads with a 1.5-second timer. Changed descriptions refresh through the public controller without another keystroke. Closing the menu stops its timer. A host without that controller updates on later candidate requests.

Document routes accept identities, not arbitrary prose or paths. The server reads the named file from the scanned resource list and removes frontmatter before translation.

The response retains text and pending and adds optional bilingualText. Pending segments retain authored text. The reader revalidates while work remains and stops its reads on close or original mode.

05Stable cache units

A persistent key includes target, surface, entity id, role, source text and provider-chain identity. Entries do not expire. The user panel and Market detail share the same document identity.

Each paragraph, heading or table cell produces independent prose units. Only oversized prose splits further. Inserting a paragraph does not change unrelated keys. Transport batches group units without changing their identities.

The localizer also reuses known text through an in-memory index. That index is not a persistent global content cache. A new entity can need translation after restart even when another entity carried the same text.

06Markdown structure

The server uses a Markdown abstract syntax tree, or AST, with GFM and math extensions. It extracts text leaves and retains code, inline code, link destinations, math and raw HTML locally.

Ordered placeholders preserve inline structure. Invalid order or empty replacements retain the original prose. The server serializes one complete document, so references, lists and footnotes retain their shared context.

Serialization can normalize whitespace and Markdown markers. It does not promise every private grammar extension of the host. Original mode retains the authored source.

07Reading modes

The host SegmentedTabs offers compact icon controls at the upper-right for original, translated and bilingual modes. Bilingual is the default. The host MarkdownText renders the selected complete document.

Bilingual paragraphs place translation below the original. Headings retain original and translated versions. Tables show the complete original table followed by the translated table, not paired text in every cell.

Names and keywords remain unchanged. Prompts and tool descriptions that enter model context retain their authored language.

08Disable and reset

Disable drops queued work, aborts active batches and prevents later fallback calls. Completed translations remain cached. A remote provider can ignore cancellation, but its old response cannot update the new generation.

Reset also removes completed entries. Generation checks reject old results and cleanup. Serialized persistence orders old writes before deletion and fresh writes after deletion.

An enabled read after reset can start fresh work. Re-enable resets failure state but does not pretranslate unopened documents.

09Limits

  • Public endpoints can change, fail or rate-limit requests. The model can consume paid quota.
  • Batch limits count source text. Masking and output expansion still require truncation handling.
  • Long paragraphs can lose translation context where they split.
  • Cache entries accumulate until reset, and each flush writes the whole cache document.
  • Closing a document stops client reads, not every server request already submitted for it.

10Verification owners

Document chunk tests cover structure and stable units. Document translation tests cover catalog assembly and protected content.

Localizer tests cover reuse, target budgets and reset races. Chain tests cover provider order and cancellation.

Reader tests cover reading modes. The decision note records supersession and known limits. Test execution and the final build belong to the integration review.
