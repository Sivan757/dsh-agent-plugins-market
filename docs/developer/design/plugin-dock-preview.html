设计要点：
1. 平时只占一行：左侧「插件」标签 + 已启用插件胶囊（含命令/技能计数），最右折叠箭头；与 todo 条、queue 条并存于 conversation.input.dock（order 10）。
2. 点击胶囊 → 高亮并展开面板：按「命令 / 技能」分组列出（数据来自 /api/agent-plugins/overview 的已启用套件），行内显示名称 + 描述 + 「插入」按钮。
3. 点「插入」→ 命令以 /name、技能以 name 填入输入框（仅带出名称，与现有约定一致）；也可直接点击行（等效插入）。
4. 面板上限 240px 滚动；无命令/技能的插件只显示来源说明。全部为宿主 dock slot 注入，不侵入输入框本体。
