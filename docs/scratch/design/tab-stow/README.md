# 页签收纳：三个方案

当前实现的问题，逐条对应到方案里的修正：

| 问题               | 观察到的现象                                       | 为什么是问题                                     |
| ------------------ | -------------------------------------------------- | ------------------------------------------------ |
| 菜单项点击语义错位 | 点已收起的页签，它出现在行内；切到别的页签它又消失 | 那是“选中”，而选中项永远渲染，所以看起来像“显示” |
| 收起后无处可查     | 只剩一个数字角标，看不出收起了哪些                 | 用户要回忆自己收过什么                           |
| 三步才能改一个状态 | 角标 → 菜单 → 管理页签… → 弹窗里勾选               | 二态控件藏在一个弹窗后面                         |
| 拖动不可发现       | 只有一个悬停提示气泡                               | 新用户不会去悬停                                 |

## 方案 A · 就地收纳（推荐）

`a-inline-stow.html`

所有页签留在同一行，收起的排在右侧分隔线之后、淡显并带“已收起 N”。点淡显项即放回；拖过分隔线即收起，拖回即放回。

- 状态与位置合一：看一眼就知道自己收起了什么，不需要菜单。
- 二态操作一步完成。
- 代价：行更长，需要横向滚动；收起的占位始终存在。
- 键盘：分隔线可聚焦，`Alt`+方向键移动焦点页签，右侧区域用 `Home`/`End` 进入。

## 方案 B · 溢出折叠

`b-overflow.html`

行内只保留可见页签，收起的进“»”按钮（带数量）；点开是勾选清单，勾选即在原位置显示或收起。

- 行最短，最像浏览器标签页的溢出处理。
- 代价：收起的内容看不见，要再点一次才知道；仍有一个弹层。
- 与宿主其它“溢出菜单”模式一致，认知负担最低。

## 方案 C · 整理模式

`c-organise-mode.html`

普通状态行内只有“整理”按钮；点开后所有页签一律显示，带复选框和拖动手柄，退出时保存。

- 误操作最少，适合页签多、顺序讲究的场景。
- 代价：多一个模式，日常切换多一次点击；整理态与普通态视觉差异大，需要额外样式。

## 我的建议

A。理由：这个控件的核心是“我收起了什么”，A 是唯一把状态本身长期可见的方案，而且把“选中”和“显示”两件事分开了——现在的缺陷正是这两件事挤在一起。B 更省空间，但把答案藏在第二次点击之后；C 最稳，但为一个低频操作引入模式。

如果选 B，改动最小：现有菜单换成行尾按钮 + 勾选清单，选中语义保持不动。如果选 A，需要重写行的布局（分隔线、淡显态、跨分隔线拖动）和键盘穿越。

## 三份稿子的共同前提

- 主题 token 用宿主真实定义的（`bg-layer-1`、`interactive-bg-hover`、`label-secondary`），不写死颜色；这三份 HTML 里的颜色只是近似值，不是实现。
- 收纳状态继续由“一行一份、两处共用”的布局存储持有；预设管理那行只显示对它成立的页签，但隐藏集合是同一份。
- 键盘路径与拖动并存，不引入第二套模式。

## 已实施：方案 A

用户选定 A。落地后的交互规格：

| 动作         | 鼠标                         | 键盘                                      |
| ------------ | ---------------------------- | ----------------------------------------- |
| 切到某个页签 | 点击                         | 方向键移动焦点即选中，`Home`/`End` 到两端 |
| 收起当前页签 | 拖过右侧分隔线               | `Alt`+`↓`                                 |
| 放回某个页签 | 点击淡显的页签（同时选中它） | 在淡显页签上 `Alt`+`↑`                    |
| 调整顺序     | 在可见区内拖动               | `Alt`+`←`/`→`（沿用工作区既有手势）       |

动效清单（全部受 `prefers-reduced-motion` 约束）：

- **选中胶囊滑动**：一个绝对定位的胶囊随选中项移动，位移与宽度各 320ms `cubic-bezier(0.22,1,0.36,1)`；宽度会变，所以不同字数的页签之间也是连续移动而不是跳变。
- **悬停**：文字转主色 + 上浮 1px，160ms 同曲线；`:active` 回到原位并缩到 0.98，给按下即时反馈。
- **拖动**：被拖项不透明度 0.45、缩到 0.98；落点显示 2px 插入指示线；指针跨过分隔线时，分隔线染色并纵向拉长 1.2 倍、"已收起" 标签转主色——手势在落下之前就有回应。
- **收起**：进入淡显组的页签从分隔线方向滑入 6px 并淡到 0.72，240ms。
- **滚动**：轨道的横向滚动是 `smooth`，键盘移动焦点的同时会把目标滚进视野。
- **错误**：写入失败时行下方出现 `role="status"` 的一行原因（原来挂在被删掉的菜单里）。

实现要点：胶囊位置是**测量**出来的（`offsetLeft/offsetWidth` + `ResizeObserver` + `resize`），不是按索引估算；测量结果做等值判断，否则同一尺寸的对象每帧都是新值，React 会报更新循环。

两个键盘/指针手势的分工保持不变：触屏仍是长按 300ms 才进入拖动，横向滑动继续归浏览器滚动。

## 反馈后的第一轮修正

| 反馈 | 改法 |
| --- | --- |
| 悬停上浮 1px 显得不方便 | 去掉位移。悬停只做两件事：文字转主色、加一层 `interactive-bg-hover` 底色。` :active` 也只换底色，不再缩放。理由写在 CSS 里：指针下的行会动，等于让瞄准邻居变难。 |
| 字体偏粗 | `font-weight` 从 500 降到 400，与宿主正文一致。 |
| 电脑上横向滚动不方便 | 三处补强：① 鼠标滚轮在轨道上映射为横向滚动（只在真的溢出时接管，否则仍滚动页面）；② 每侧多出可滚时显示一个 `22px` 的 chevron 按钮，点击滚动 80% 视口宽；③ 滚动/缩放/布局变化时重新计算两侧可达性，按钮不会常驻成摆设。 |
| CodeMirror | 不再推进，维持现状（宿主只提供只读高亮器 + 纯文本 `InlineEditor`，没有可编辑代码编辑器）。 |

Chevron 用的是宿主 `IconChevronLeftOutlineMedium` / `IconChevronRightOutlineMedium`，没有新增图标或依赖。

## 反馈后的第二轮修正（当前实现）

| 反馈 | 改法 |
| --- | --- |
| 字体太大、样式太重 | 字号 12px、行高 18px、内边距 4×9、圆角 8px、字重 400；选中态只换底色，去掉阴影层次。收起态再小一档（11px、55% 不透明）。 |
| 左右按钮改为行内悬浮 | 两个 chevron 改成 `position: absolute` 的覆盖层，`opacity: 0` 常驻隐藏，`.wrap:hover` 时才出现；`pointer-events` 同步开关，避免挡住点击。不再占布局宽度。 |
| 不再显示“已收起”和分隔符 | 整块 group 结构删除：没有标签、没有分隔线。收起的页签只是行尾更淡的页签。 |
| 不再展示悬浮提示与收起 | `TabHoverActions.tsx` 整个删除（悬停气泡、左右移、收起按钮、引导提示），相关 12 个文案键与全部 `tabHover*` / `tabManage*` 样式一并移除。 |
| 使用长按拖动排序 | 鼠标与触屏统一为 **长按 280ms 后才能拖动**；按下后先移动超过 4px 视为滚动/点击，不进入排序。松手未移动仍是点击选中。 |

### 现在的行结构

```
[已选胶囊] [可见页签…] [更淡的收起页签…]   ← 一个 tablist，无分组包裹
覆盖层：悬停时左侧/右侧出现 chevron（仅在可滚时）
```

收起/放回：拖到最后可见页签右侧 16px 之外 = 收起；点击淡显页签 = 放回并选中；键盘 `Alt`+`↓` / `Alt`+`↑`。

### 为什么这样更稳

上一版把“分组”当成了信息：需要分隔线、标签、包裹容器，还导致行内换行——截图里的两行就是这样来的。现在行内只有一个 tablist 和它的子元素，`flex-wrap: nowrap` 明确禁止换行，宽度压力靠滚动与覆盖层按钮解决。

## 第三轮（最终形态）

按最新反馈，收纳功能整体撤掉，行回到最简单的形态：

- **页签样式与顺序**：恢复为宿主式的 chips，选中项自带 `bg-layer-1` 底色；顺序完全按存储的顺序显示全部页签，不再有隐藏。
- **左右行内按钮**：按钮是行内元素（占位、不遮挡），只在对应方向真的溢出时出现，点击**滚动一个页签的宽度**（读取第一个页签的实际宽度，不是视口比例）。
- **溢出渐隐**：只有被裁掉的那一侧加 `mask-image` 渐变；两侧都裁就两侧都加；不溢出则没有渐隐。
- **长按拖动排序**：280ms 长按后进入拖动；按下先移动超过 4px 视为滚动或点击抖动，不排序。
- **移除**：选中胶囊（截图里那块灰色浮块）、长按变灰（拖动反馈）、悬停气泡与引导、以及全部收纳相关的文案与样式。

上一版截图的两个疑点因此不再存在：灰色浮块是“选中胶囊”，长按变灰是“拖动中的提示”——两者都被删除，而不是调参。
