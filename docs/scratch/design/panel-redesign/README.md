## 1. 第一性原理：这个页面到底是什么

一个**资源目录页**的职责只有三件事：

1. **看见有什么**——当前作用域里有哪些条目、各自是否可用；
2. **找到要的那一条**——条目多时靠搜索/筛选，不靠滚动找；
3. **对它做一件事**——查看内容、编辑、删除、或理解它如何影响模型。

任何不服务于这三件事的元素，都是噪音。这解释了上一版为什么错：会话目录横幅、项目分组里那四行"未创建"，既不是"有什么"，也不能被"找到"或"操作"，纯噪音。

## 2. 一致性原则（不可协商）

「技能」「快捷指令」「专家」已经是这个产品里的目录页基准。系统提示词与输出风格**必须**是同一套：

- 头部：标题式说明一句 + 右上角动作（新增、刷新）；
- 工具条：搜索框（占宽）+ 计数分段（全部 N / 用户 N / …）+ 视图切换（网格/列表）；
- 内容：卡片网格；卡片 = 左侧 3px 状态色条 + 标题（等宽字体）+ 来源标签 + 一句描述 + 底部一行元信息；
- 交互：**整卡可点**，点开进入详情对话框；破坏性操作在对话框内，不在卡片上；
- 状态：加载、空、错误、禁用四种表现各有固定位置。

不允许为这两页发明第二种列表语言。

## 3. 页面一：系统提示词

### 3.1 条目是什么

一条 = 一个会被注入的指令文件。用户级两条（`~/.dsh/AGENTS.md`、`~/.agents/AGENTS.md`）。

### 3.2 卡片显示

- 标题：文件路径（等宽）；
- 标签：已加载 / 未创建 / 重复 / 被截断（颜色随状态）；
- 描述：该文件的首行摘要（没有内容则显示引导语"点击创建"）；
- 元信息：字节数；重复项显示"内容来自 X"。

### 3.3 详情对话框

- 头部：路径 + 状态标签；
- 主体：文件内容（可编辑，等宽，行数上限 300px 起）；
- 底部：字节数 / 上限、取消、保存；已存在时额外提供删除（二次确认）。

### 3.4 页面级信息（保留，但不占视觉重心）

- 注入预算：一条细进度条 + `已用 / 总量`，超限变色；
- 注入给模型的文本：默认折叠，展开后可复制。

**移除**：会话目录横幅、项目的四行空候选。

## 4. 页面二：输出风格

### 4.1 条目是什么

一条 = 一种输出风格（内置或用户自定义）。

### 4.2 卡片显示

- 标题：风格名（等宽）；
- 标签：内置 / 用户 / 已启用；
- 描述：该风格的说明一句；
- 元信息：来源（如 `output-styles`）或文件路径。

### 4.3 分组问题的两个候选（需要你选）

- **A（推荐）**：不分组，用计数分段区分来源（全部 / 内置 / 用户）。列表更平，和「快捷指令」完全一致。
- **B**：保留两个分组小标题（内置、用户），每组内用同样的卡片网格。来源更醒目，但多两行标题。

### 4.4 详情对话框

头部：风格名 + 标签；主体：风格正文；底部：取消、保存（用户自定义）/ 只读提示（内置）。

## 5. 页签行规格（已定，不再反复）

- 一行页签 + 1px 边框，圆角 10px；
- 溢出时：**边框内**一侧加 34px 窄渐隐（只盖文字，不盖边框）；同侧浮出**扁长箭头（28×18）**；
- 箭头与渐隐**只在鼠标进入页签行时出现**，离开即隐藏；点一次滚动**一个页签宽度**；
- 选中项自带底色；长按 280ms 后才可拖动排序，拖动中页签抬起并跟随指针。

## 6. 验收标准

1. 系统提示词页与「快捷指令」并排截图，卡片、工具条、间距**看不出是两套实现**；
2. 页面首屏不出现会话路径、不出现"未创建"的项目候选；
3. 任一卡片点击后进入详情，编辑能保存、删除有二次确认；
4. 搜索能在输入时即时过滤；计数分段与视图切换可用；
5. 页签行悬停出现箭头与渐隐，离开消失，边框始终完整。

## 7. 原型

- `prototype-a.html`：输出风格不分组 + 计数分段（推荐方案 A）
- `prototype-b.html`：输出风格保留分组标题（方案 B）

两个原型都包含**完整的**系统提示词与输出风格页：搜索、筛选、视图切换、卡片、详情对话框、预算条、注入预览、空状态，以及页签行的箭头/渐隐/悬停行为。

## 8. 移除内置输出风格（决定，待执行）

要求：插件不再自带输出风格，风格只来自插件解析（suite）与用户自定义。

这不是样式改动，会改变默认注入行为。当前插件默认选中 `builtin:default`，即"注入一个空段落"；移除后默认为**未选择**，提示里不再有 output-style 段。影响面：

| 位置                    | 改动                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| `market-contracts`      | `OutputStyleSource` 去掉 `'builtin'`；删除 `OUTPUT_STYLE_DEFAULT_ID`、`BUILTIN_DEFAULT_NAME` |
| `market-runtime` 应用层 | 删除 `readBuiltinStyles` 与内置正文常量                                                      |
| `output-style-service`  | 列表只拼 用户 + suite；`resolve()` 去掉内置分支与"回落到内置"的分支，未命中即不注入          |
| 状态                    | `defaultOutputStyleState()` 返回空选择；读到 `builtin:*` 视为未选择                          |
| UI                      | 分段只剩 全部 / 插件 / 用户；行内不再有 `builtin` 标签                                       |
| 测试                    | `output-styles.test.ts` 的 10 个用例按新契约改写（当前有 9 个以 "内置为默认" 断言）          |

迁移规则（建议直接采纳）：已存的 `builtin:*` 选择读作"未选择"，不写回，不报错。
