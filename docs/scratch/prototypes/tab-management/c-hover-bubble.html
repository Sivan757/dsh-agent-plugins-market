方案 C · 长悬停气泡 + 右缘渐隐

不在行内放任何控件。页签被悬停 620ms 时，它上方浮出一枚小气泡（收纳 / 置顶查看）；溢出的页签在右缘化成一层渐隐，点渐隐才展开完整列表。

Agent Plugins
把指针停在 语言引擎 上约 0.6 秒，气泡浮现，点"收纳"即可。或者点右缘的渐隐区展开全部页签。
状态 1静止 · 只有渐隐，没有图标
溢出的能力用"渐隐 + 数字"表达，比一个 ⋯ 图标更轻，也给出了信息（还剩几个）。
状态 2长悬停 · 620ms 后页签上方浮出气泡
气泡 scale .92→1 + 上浮 4px，弹入曲线 cubic-bezier(.34,1.56,.64,1)。指针可直接移入气泡，移开 240ms 后自动淡出。
状态 3展开 · 右缘点击后的完整列表
已收纳 2 项
全部页签
列表向上微移 4px 淡入，每项 hover 右移 2px。列表内直接点选或收纳，不需要再进一个弹窗。
