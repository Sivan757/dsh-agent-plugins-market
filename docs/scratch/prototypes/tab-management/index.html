页签管理 · 三个方案

目标：页签行的可用空间不再被一个常驻按钮吃掉，同时让「收纳」这件事自己被发现。三个方案都去掉了行尾按钮，用不同方式把入口藏进已有的手势里。每页都可以切深色、重放引导。

方案 A · 边缘磁轨拖拽

行尾 10px 留白即握把。指针进入 56px 热区，一条磁轨浮出；向左拖依次收纳，向右拖依次取回，每格 34px 磁吸。

零常驻控件磁吸回弹可加 ⌥ 点击直接收纳
方案 B · 长按抬升长按

长按任意页签 260ms，进度环绕满整行 translateY(-3px) 浮起进入编辑态，页签可拖动；拖到右缘落点区松手即收纳。

零常驻控件"灵光一闪"式抬升触屏同样成立
 方案 C · 长悬停气泡长悬停

悬停 620ms，页签上方浮出小气泡（收纳 / 在列表中看）；溢出的页签在右缘化成渐隐 + 数字，点渐隐展开完整列表。

零常驻控件渐隐带计数气泡与列表共用一处入口

三个方案的共同约束

  • 页签行严格保持宿主 role="tablist" 的漫游焦点与 ←/→/Home/End 键盘行走；入口渲染在 tablist 之外或作为页签内部的 popover，不进入焦点序列。
  • 键盘等效路径必须存在：⌥+←/→ 移动"收纳边界"，或页签聚焦时按 ⌫ 收纳。任何鼠标手势都要有键盘版本。
  • 至少保留一个可见页签（market 固定不可收纳），深链打开已收纳页签时临时显示、不写回。
  • 每次手势结束只落一次盘（乐观更新 + 失败回退并说明原因），不给每个中间帧写文件。
  • prefers-reduced-motion 下取消位移与弹入，仅保留透明度切换。

建议

  • 默认组合：A 的边缘磁轨作主入口（无所占空间、可逆、一次拖到位），C 的右缘渐隐 + 计数作被收纳项的可见线索，B 的长按抬升只保留给触屏与"选中页签后按 ⌫"。
  • 首次使用：跟随 C 的气泡做一次 1.8s 引导，比 A/B 的拖拽更不容易误触，也不打断阅读。
