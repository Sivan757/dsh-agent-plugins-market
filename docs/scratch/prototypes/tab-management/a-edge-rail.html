方案 A · 边缘磁轨

不加任何常驻按钮。页签行右缘留 10px 留白，指针进入 56px 热区时一条磁轨浮出；向左拖依次收纳，向右拖依次取回，每格 34px 磁吸。

Agent Plugins
把指针移到页签行最右端（约 12px 宽的一条缝），磁轨会浮出来。向左拖动即可把 语言引擎 / 钩子 收起来。
状态 1静止 · 无按钮
右缘只有 10px 视觉留白，磁轨 opacity 0。常驻按钮带来的视觉重量被彻底去掉。
状态 2接近 · 磁轨浮出，行内让位 14px
180ms 弹入：scaleX 0.55→1 + 透明度，底座泛起品牌色光晕。行尾 padding 10→24px 是一次轻微的“呼吸”，提示这里可以拉。
状态 3拖动 · 收纳层浮出 + 磁吸回弹
收纳层在行上方浮出，幽灵芯片依次滑入（stagger 40ms）。每跨一格磁轨 scaleX 弹一下（spring 180ms），松手立即落位，整个会话只写一次盘。
