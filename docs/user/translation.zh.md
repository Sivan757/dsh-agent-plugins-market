# 翻译

在插件配置卡片中开启 **翻译**，即可按界面所用的简体中文或英文阅读描述和文档正文。中文默认开启、英文默认关闭；你保存的选择优先，直到点击「恢复默认」重新采用语言默认值。英文界面手动开启后也能将中文翻成英文。名称与关键词保持不变，用于搜索、排序、复制和调用。

翻译按下列顺序尝试，等待期间原文仍可阅读：

1. **Google Translate** —— 无需 key 的公开端点，超时为 3 秒。
2. **Microsoft Translator** —— 无需 key 的公开端点，超时为 15 秒。
3. **你的默认模型** —— 有可用模型路由时使用，超时为 30 秒，可能消耗你的模型额度。
4. **上游原文** —— 没有 provider 作答时显示。公开端点没有可用性承诺；失败的 provider 会被跳过，直到重新开启翻译、重置缓存或重启进程。

读取面板或菜单候选时才请求描述翻译，不在启动时遍历翻译。斜杠菜单立即返回当前描述。菜单保持打开时，最多追加 40 次读取，间隔至少 1.5 秒，描述改变后无需继续输入即可刷新。关闭菜单或停用翻译即停止这些读取。达到上限后，后续候选请求仍可再次重验证。宿主缺少公开菜单控制器时，只在后续候选请求中更新。

技能、快捷指令或专家的详情打开时文档已展开，可在文档标题栏收起；在市场套件详情中则展开文档行。文件名同行的图标切换原文、译文和双语，不会折叠文档。悬停可查看标签，键盘可以切换模式。默认显示原文；模式是全局共享的，点一次即对所有文档生效，展开文档本身不会触发翻译。切到译文或双语时，逐段显示原文和译文。工作期间，旋转图标替换当前模式图标，正文不显示加载文字。未展开文档不预翻译。原文模式停止后续翻译读取，但已提交的服务端工作仍可完成。

滚动文档时，控件随文档标题栏保持在滚动区域顶部；到达该文档末尾或折叠后，标题栏退出吸顶位置。

读取失败或部分段落无法翻译时，选中模式图标会变成警告。悬停可查看错误，点击该警告即可重试。重试重置当前文档的失败记录，并重新允许尝试此前失败的 provider，不清空已完成译文。原文和已完成的段落仍可阅读。每次翻译读取的时限为 15 秒，覆盖响应体读取，不是整篇翻译的总时限。

正文以自然段为单位翻译。短段整段发送，长段只按完整句子分组。若单句超过安全长度，整段保留原文并标记失败，不截断句子。每段所有部分完成后才显示整段译文，不混合半段原文与译文。代码、链接目标、数学内容和原始 HTML 不参与翻译，双语表格按整表上下对照。

译文缓存在本地且不会过期。用户面板和市场详情共享文档段落缓存。相同文档身份、段落文本、目标语言、provider 链和翻译策略可以跨重启复用。插入或编辑一段不影响未改动的相邻段落。新版正文策略不复用旧版切片缓存，因此首次重新打开文档会产生一次性重译开销，可能使用模型额度。已有描述缓存保留，源文件不改写。

关闭 **翻译** 后，各个面显示原文，未启动的工作被取消，后续回退调用不再发起，已完成的缓存仍保留。插件会请求取消活动调用，但远端 provider 仍可能完成已收到的工作。「重置缓存」清空已完成的记录，并使旧请求失效，阻止其回填；之后开启状态下的读取可以发起新工作。重新开启翻译也会重试此前失败的 provider。

本插件注入会话的提示词与工具描述不翻译：它们保持作者撰写时的语言。
