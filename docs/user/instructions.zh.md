## 页面显示什么

**规则**页签列出宿主会注入的 `AGENTS.md` 文件，一个存在的文件一张卡片，点开即可编辑它。发现、加载顺序、去重与字节预算全部来自宿主包 `@deepseek-ai/dsh-agent-instructions`，因此页面与提示词不会互相矛盾：每一行的状态都来自模型实际收到的文本。

页面按会话的工作目录读取链条。设置页本身不在任何会话里，所以那里读的是宿主进程的工作目录，并在页头下方用一行说明。页面不渲染注入后的文本：文件清单与状态标签才是它能与提示词保持一致的部分。

## 加载顺序

先是两个用户级根目录，然后是从项目根到会话目录的每一层目录。

- `$DSH_HOME/AGENTS.md`，宿主主目录，除非设置了 `$DSH_HOME`，否则是 `~/.dsh`。
- `$DSH_AGENTS_HOME/AGENTS.md`，共享 Agent 根目录，除非设置了 `$DSH_AGENTS_HOME`，否则是 `~/.agents`。
- 每个项目目录按顺序读取：`AGENTS.md`、`CLAUDE.md`、`AGENTS.local.md`、`CLAUDE.local.md`。
- 项目根是会话目录及其上层中第一个含 `.git` 的目录。它可以是目录，也可以是链接工作树写出的文件。

## 哪些文件名会被加载

两个用户级根目录只加载 `AGENTS.md`。那里既没有 `CLAUDE.md`，也没有本地覆盖文件，所以页面不会提议创建它们。

项目目录里四个文件名都会加载。页面会为没有指令文件的目录补一行，标为未创建，这一行提供的操作就是创建。

## 内容重复

在同一个候选组内，去掉首尾空白后内容相同的文件只注入一次。两个用户级根目录属于同一个组，因此两处内容相同的 `AGENTS.md` 只注入一次，且以宿主主目录为准。每个项目目录自成一组，因此与同目录 `AGENTS.md` 内容相同的 `AGENTS.local.md` 会显示为内容重复，并指出真正承载内容的那一行。

## 字节预算

页面报告两个上限：整段注入内容 65536 字节，单个文件 1048576 字节。两者都是宿主随包发布的取值，也是它读取链条时用的取值。它们只用于显示，不是设置项，因为宿主并不导出解析后的值。若某个 profile 调高了它自己的 `maxBytes` 或 `maxSourceBytes`，页面仍会显示随包发布的数字，这里无法察觉。写明而不做成可配置，是刻意的取舍：一个独立于宿主的插件设置会描述模型从未得到的预算。

超出预算时先省略较宽的目录，只有最具体的那个文件会被截断。超过单文件上限的文件完全不会被加载，页面会给出这个原因而不是把它列进省略清单。预算为 0 或更小时，指令加载整体关闭。

## 单行状态

| 状态           | 含义                                               |
| -------------- | -------------------------------------------------- |
| 已加载         | 该文件的正文出现在注入的提示词里。                 |
| 已截断         | 该文件是最具体的那个，被裁到剩余预算能容纳的长度。 |
| 超出预算       | 较宽的文件，被预算省略。                           |
| 超过单文件上限 | 大于 1048576 字节的单文件上限，因此从不加载。      |
| 内容重复       | 与组内更早的文件去空白后内容相同，只注入一次。     |
| 未注入         | 文件存在却不在提示词中，且没有可归因的原因。       |
| 未创建         | 文件不存在。页面对这一行提供的操作是创建。         |

## 创建、编辑与删除

每个操作只写一个链条能加载的文件。请求只给出作用域、项目相对目录与候选文件名，从不给出路径，因此页面到不了本会话不注入的文件。

写入是原子的，只有在链条规定的位置才会创建上级目录；编辑器拒绝超过 1048576 字节单文件上限的文本，因为这样的文件永远不会被加载。编辑器会随输入实时显示两个上限的字节数。

同一个文件可以在链条上占两个名字，例如 `CLAUDE.md` 是 `AGENTS.md` 的符号链接。删除任一名字都会报告另一个名字，并说明被删除的这一项本身是不是链接，以便判断剩下的名字还能否解析到内容。

## 页面不可用时

宿主包是可选依赖。profile 没有提供 `@deepseek-ai/dsh-agent-instructions` 时，页面显示一条点名该包的通知，而不是整页失败，工作区其它部分不受影响。
