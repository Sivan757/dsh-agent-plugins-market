## 什么是输出风格

输出风格是一段有名字的指令文本，用来改变模型的回答方式。**输出风格**页签为每个工作区选一个，选中的文本会作为一段系统提示进入会话。

每个工作区只选中一个风格。默认风格不带任何文本，因此什么都不注入，也是关闭风格的方式。

## 进入提示的内容

这一段的形态是：一行标题写着风格名，下面是风格的完整正文：

```text
## Output style: concise
Answer first. The first line is the result, the fix, or the direct answer...
```

标题属于这段文本本身，因为宿主只是用空行把各段拼起来，自己不加标题。没有标题，两段指令会连在一起，读提示的人也看不出风格从哪里开始。

页面上的预览就是这个文本。它与服务端生成这一段用的是同一个函数，所以预览与提示不可能不一致。

## 风格来自哪里

| 来源 | 位置                                     | 说明                                                    |
| ---- | ---------------------------------------- | ------------------------------------------------------- |
| 自建 | `<Agent 布局根>/output-styles/<名称>.md` | frontmatter `description:` 加正文，在页签里创建和编辑。 |
| 套件 | 通过 SessionStart 钩子打印文本的市场套件 | 明确抓取一次，之后保存为文本。                          |

插件不自带风格。你自建的风格存成 Markdown 文件，跟随你的 Agent 布局根，其它工具也能读。未选择任何风格时，提示里没有 output-style 段。

## 套件风格与抓取

Claude Code 的输出风格插件靠会话启动时运行一个程序来给出文本。本插件在你浏览页面时不会运行它。页签列出该套件，**抓取文本**会把它声明的 SessionStart 钩子在你的用户主目录下运行一次，有固定超时与输出上限。它打印出来的文本就是此后进入提示的内容。

抓取被做成单独的动作，一是因为运行套件程序是一次副作用，二是因为影响每次回答的文本应该先被人读过。风格可用之前，预览会先显示抓取到的文本。

抓取与套件声明、版本和钩子命令的指纹绑定。套件一旦变化，这一行会显示抓取已过期、停止注入，并提示重新抓取。没有任何人确认过的版本，其文本不会进入提示。

## 关闭风格

选中 **default**。它不带文本，这一段渲染为空，宿主会直接把空的提示段去掉。

## 说明

- 选择按工作区保存，与其它工作区状态放在一起。
- 删除一个自建风格后它不再注入；原本选中它的工作区回落到默认风格。
- 风格名是文件名词干：小写字母、数字、点、短横线与下划线。
