在 **插件 → 已安装 → Agent 扩展** 中配置本扩展。显示名称、介绍和设置文案跟随 DSH 界面语言。配置页承载本插件的全部开关：**扫描项目 Agent 布局**（`scanProjectLayouts`，默认关闭，见[项目布局](resources.zh.md#项目布局)）、**MCP 增强**、**下载区域**、**后台自动更新来源**（`autoUpdateSources`，默认关闭，每 6 小时刷新一次全部已配置来源）、**体验反馈工具**与**翻译**（`translationEnabled`，默认开启，你保存的选择优先，见[翻译](translation.zh.md)）。卡片会暂存你的选择，按下「保存」后才生效，因此屏幕上显示的就是保存会写入的内容；标记为**已自定义**的设置还会提供「恢复默认」，把该设置交还给插件。**下载区域**初始为**跟随界面语言**，再次选择它即清除你的显式选择。

## 会话扩展预设

Agent 预设管理器默认开启；不需要入口时可在插件设置中关闭，该开关只控制入口显示，不改变会话授权或已有选择。开启期间，空白会话和进行中的会话均在「权限」右侧显示 Agent 扩展图标按钮，悬停或聚焦可查看所选预设名称。菜单提供选择已保存预设和管理当前工作区预设库两个入口。扩展预设不会替换宿主的基础 Agent 预设。

- 市场列出已安装的市场套件。项目资源显示在各自能力页签中。Hooks 把各事件列在一起，每行标注自己的阶段。已有预设保留原选择。用户和项目的命令 hooks 可逐项开关；已安装市场套件的 hooks 跟随套件选择，管理窗把它们列成只读行并标注「跟随套件」。hook 行打开它自己的只读声明：完整命令、声明的匹配条件、声明的超时与宿主支持情况。
- 工作区默认预设只用于新会话。在当前会话中编辑已选或待选预设会更新该会话。其他会话各自保留独立副本。
- 会话运行时处于活动状态时选择已保存的预设，将在该会话的下一次用户请求生效。进行中的中途引导（steer）与工具调用不受影响。在管理窗口中单击资源卡片或开关，可在预设内启停资源。保存失败时可以保留草稿重试，也可以放弃修改。
- 在不同工作区的面板之间复制、粘贴预设，会创建独立副本。传输内容只有名称和资源标识，不含凭据或服务器配置。本地配置（用户 hooks 与项目布局套件）的标识不会随副本传输；其授权跟随所选资源本身。
- 预设可显式启用全局已停用的有效已安装扩展，不修改全局设置或源文件。原生技能和套件资源在会话间独立生效；其他会话仍需使用的共享服务会保持挂载。未安装、无效或不受支持的资源仍不可用。宿主兼容后端或其他插件提供的 MCP 工具仍由全局管理。
- 预设详情中的开关只修改预设内的资源选择。文档和服务配置保持只读。凭据、认证和全局工具设置请在对应的设置页面修改。
- 选择更新失败时，入口会提示会话尚未就绪。显式恢复会还原最后一次已提交的选择或已捕获的初始选择。如果首次捕获在记录任何选择前失败，恢复会按原来的新会话或旧会话分类重新捕获。恢复成功后，排队输入无需再次发送即可继续；空队列不会发起模型请求。再次失败时仍等待下一次显式恢复。发生在会话启动且没有任何重试的失败，会让会话以不含管理资源的方式运行而不是等待，此后恢复是找回它们的途径。待提交和已提交记录继续持久保存，新的选择与唤醒标记不进入模型输入。旧历史中的占位消息保持不变。

## 体验反馈

`feedbackEnabled` 默认 `true`。宿主提供 tools 和 settings 时，启用面向模型的 `report_market_issue` 工具，在本插件的 GitHub 仓库提交 issue：装有并已登录 `gh` 命令时用 `gh`，否则用 `GITHUB_TOKEN` / `GH_TOKEN`。两者都不可用时不会提交任何东西：工具会在浏览器中打开预填好的「新建 issue」页面，并把完整 issue 文本与链接返回给模型转交给你。成功提交后 60 秒内不会再次提交。在插件配置卡片中关闭该设置即可注销工具。
