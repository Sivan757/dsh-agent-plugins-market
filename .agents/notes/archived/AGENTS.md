# AGENTS.md — Archived Agent Notes

Archived Agent Notes under the class directories are frozen historical snapshots, not current authority. Never edit, reformat, translate, repair, delete, or move a sealed artifact; use an active Agent Note or current documentation for new decisions and facts.

The archival change may only relocate the complete English/Chinese pair, insert the identical `Archived: YYYY-MM-DD` line below both `Status: implemented` lines, and repair or delete inbound links. Do not inspect, verify, or repair links out of archived notes.

Run the `dsh-archive-agent-notes` workflow for every archival decision. This repository has no seal verifier — the freeze is enforced by this rule and by review.
