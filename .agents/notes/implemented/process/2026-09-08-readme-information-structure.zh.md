# Agent Note: README 信息结构

Status: implemented

## Problem

README 逐步堆积实现细节和重复的上手内容，只强调 Claude Code 的标题也已无法描述当前工作区。部分运行时和配置说明落后于源码。

## Decision

中英文 README 从用户目标出发，依次组织快速开始、日常使用、兼容边界、问题排查和文档链接。布局方言支持与运行时能力支持分为两张表。详细配置进入成对的使用指南，文档站直接相关的表述同步采用相同实现事实。

按用户要求，README、使用指南与文档站均不再展示仓库与发布版本差异提示，使用 Playwright 截取实际运行的六页签插件工作区。能力矩阵区分上游文档约定与本插件实现，并于 2026-09-08 对照厂商文档与源码核验；Codex 的 MCP 行采用官方文档的 `mcpServers` 包装写法，Universal 行引用 OpenHands SDK。依赖声明不表述为已验证的最低宿主版本。共享 SVG 图标是经 `gpt-image-2`（kie.ai）生成的四拼块风车标记，矢量化成双色 SVG，同时用于 README 和浏览器 favicon。

替代检查未发现负责 README 组织方式的已有活跃记录。来源获取、缓存和工作区的既有决策保持活跃，不受本次改动影响。[面向用户的文案不展示决策与多余提示](2026-09-11-user-facing-copy-omits-decisions.md) 随后把移除发布版本提示背后的立场推广到所有面向用户的界面，部分取代本记录的文案规则，其结构决策保持有效；两条记录互相链接。

## Alternatives considered

**继续扩充功能列表。** 否决，因为这混合首次使用说明与实现参考内容，并与 FAQ 重复。

**在首页保留对比表。** 否决，因为其他项目的能力声明需要单独持续核验，也无助于完成主要安装路径。

## Consequences

README 缩短，详细配置仍可通过链接访问。行为变更时仍需同步使用指南与文档站。截图记录本地实际运行界面，不代表所有运行时能力均已验证。本次不提供经过验证的宿主版本矩阵。
