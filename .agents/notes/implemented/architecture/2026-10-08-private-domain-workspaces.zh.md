# Agent Note: 私有领域工作区保留单一公开产物

Status: implemented

## Decision

八个私有工作区分别负责目录、运行时、MCP、LSP、翻译、浏览器界面、产品装配和无状态契约。公开安装包仍为 dsh-agent-plugins-market。

领域消费者通过显式包入口导入。契约提供可移植子路径和独立宿主类型扩展。依赖规则禁止反向装配依赖、运行时直接依赖具体连接器、浏览器依赖服务端以及循环依赖。

根 TypeScript 工程把所有服务端包编译到 lib 下。公开根入口转导出装配包。浏览器入口仍是单一编译产物。公开根清单不包含私有工作区依赖。

## Alternatives considered

仅调整内部目录不能提供明确的工作区归属与清单依赖检查。用户选择了真正的私有工作区。

独立 npm 发布需要新包名、版本协调和安装策略。用户选择单一公开产物，因此 release-please 保持不变。

新增服务端打包器会引入模块解析和动态导入变化。根 TypeScript 编译保留相对导入及现有外部依赖。

通用可变共享服务会模糊归属。契约工作区只包含无状态记录、辅助函数和类型端口，不包含存储或运行时注册。

通用注册容器会新增宿主已经负责的生命周期策略。因此，会话装配保留在组合包内部，沿用原有注入作用域和清理顺序。

## Consequences

目录发现不再实例化翻译或连接器服务。运行时从装配层接收具体连接器工厂。翻译呈现规则归翻译服务负责。MCP 与 LSP 配置用例拥有独立归属。

组合包内部的会话装配负责各 Agent 的映射、选择应用、项目读取缓存及角色查询。套件呈现归独立的只读模块负责。两者保留实时回调和既有生命周期顺序。

本次迁移保留根目录集成测试集。包入口冒烟测试补充内部单元测试。全部 1,860 个冻结测试身份继续执行。

[迁移契约](../../../../docs/developer/design/domain-workspace-refactor.md)记录归属和排除范围。[行为冻结](../../../../docs/reference/behavior-freeze-2026-10-07.md)仍为对比基线。

## Related

本决策改变源码归属，不改变现有生命周期、设置和翻译决策。其实现引用随源码迁移。不修改已冻结的归档记录。
