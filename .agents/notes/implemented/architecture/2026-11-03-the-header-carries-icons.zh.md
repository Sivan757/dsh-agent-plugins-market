# Agent Note：页头放图标，菜单从图标展开

Status: implemented

## Problem

共享页头的设计是放两颗 24px 图标按钮，文字进 `title` 与 `aria-label`，这样宽度不随语言变化。有一个面破坏了它：系统提示词面把新增动作画成文字按钮，理由是那个动作会展开候选路径菜单，而「菜单」感觉需要一个字。结果是这个页头比其它页签高 4px，工具栏也随之落得更低，并且随语言而变。

## Decision

- **页头与工具栏的每个动作都是 24px 图标按钮**，文字放在 `title` 与 `aria-label` 上。会展开菜单的动作仍然是页头动作：图标挂菜单，菜单负责说出选项。
- **文字按钮属于对话框页脚与正文**，那里周围的句子已经说明了动作是什么（保存、取消、删除）。
- **规则写进其它客户端样式规则所在处**——`AGENTS.local.md` §客户端样式规范，紧挨卡片解剖那条。该文件按设计被 gitignore，因此这条 note 是同一规则的可追踪记录。
- **修的是那一处违规，而不是弯折规则**：`InstructionsPanel` 现在渲染与其它面板相同的图标按钮，菜单保留。

## Alternatives considered

- **保留文字按钮，让页头长高。** 否决：页头是共享的，它的高度在中文与英文之间变化，正是这条规则要消除的不一致。
- **为了「诚实」，把所有带菜单的动作都改成文字按钮。** 否决：菜单本身会给选项命名，触发器不需要再说一遍；页头里的文字触发器只在一个语言里多占宽高。
- **把规则放进可追踪的样式指南。** 已考虑并部分执行：在出现拥有它的设计文档之前，可追踪的家就是这条 note。

## Consequences

- 九个面在两种语言下画出相同的页头高度（实测 28px）。
- 将来新增的「展开菜单」动作使用图标，选项由菜单命名。
- 本地样式段与这条 note 必须一致；改一处要同步另一处。

## Verification

- 九个面实测：新增控件全部为图标；系统提示词页头实测 28px，修复前它也是 28px，但与其它页签不同高。
- `packages/market-ui/test/client-instructions-panel.test.ts` 在图标触发器下仍然通过（打开的还是同一份菜单）。
