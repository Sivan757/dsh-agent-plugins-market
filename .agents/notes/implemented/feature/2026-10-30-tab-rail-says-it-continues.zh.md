# Agent Note：页签条不用悬停也能说出「后面还有」

Status: implemented

## Problem

九个设置页面很少能挤进一行，而页签条的两个提示在静止状态下都看不见。翻页箭头等指针，于是一行被截断的页签看起来就像到这为止。边缘渐变更糟：它从 `interactive-bg-hover` 起渐变，而那正是轨道自身 6–8% 的淡色，等于用轨道的颜色盖在轨道上，被截断的字仍然完整可读。560px 的截图显示文字在字形中间被硬切，没有任何「还有内容」的信号。

## Decision

- **被裁切的一侧用行自身的遮罩溶解，而不是色带。** `TabRail` 本来就在测量两侧，现在它写一条 `mask-image`，把末尾 40px 的内容渐隐到透明。遮罩不涉及颜色，因此两种主题、任何面板表面上都成立；色带必须猜表面，而它拿到的颜色等于「不可见」。
- **箭头在那一侧被裁切时常显。** 它只在内容确实藏到边后时存在，所以它是事实而不是噪音：读者不用移动指针就知道行还在继续。悬停仍然提亮，聚焦画上业务色描边。
- **按侧给出提示。** 滚到中间时两侧都遮罩，滚到末尾只剩左侧，起点的右侧同理。
- **行在下一帧与字体就绪后再测一次。** 对话框挂载内容时布局还在落定，会测出一行「放得下」，而尺寸观察回调可能就在同一帧里跑：第一次真宿主会话里出现了硬切、既无溶解也无箭头，直到行被滚动才恢复。于是下一帧与字体就绪时各再测一次，提示与实际看到的那一行一致。

## Alternatives considered

- **保留色带、只改颜色。** 否决：色带必须匹配面板所在的表面，而轨道的淡色让每个候选都略差一点；第一次用 `bg-layer-1` 的尝试就在「面板表面其实是页面」的情形下画出了一条浅带。
- **用滚动阴影代替遮罩。** 否决：同样的颜色问题，而且阴影读作层次，不读作「还有内容」。
- **继续只在悬停时显示箭头，把渐变加宽。** 否决：坏掉的正是渐变；箭头是点击目标，常显不产生额外成本。

## Consequences

- 最后一个可见页签刻意只露出一半：遮罩恰好盖到内容结束的位置。
- 这里用到的 API 是 `mask-image` 及其 `-webkit-` 前缀，宿主支持的各浏览器早已具备。
- 样式表不再保留两个渐变色类，页签条只有一种边缘处理。

## Verification

- `packages/market-ui/test/tab-rail-drag.test.ts` 断言裁切侧的行带有遮罩渐变、样式表不再有渐变色规则、翻页箭头没有零透明度的起点，以及首帧之后才溢出的行仍然拿到遮罩与箭头。
- `market-dev` profile 在真宿主上提供了一个构建产物：打开设置里的 Agent 扩展时，右侧立刻有溶解与箭头，而上一版构建是硬切。
- 预览夹具在 560px 与 760px 渲染九个页签：560px 时最后一个页签溶解进表面，760px 时没有内容被藏，因此什么都不渐变。
