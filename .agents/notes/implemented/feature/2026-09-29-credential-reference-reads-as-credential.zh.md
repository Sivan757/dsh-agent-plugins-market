# Agent Note: A secret reads as a secret

Status: implemented

## Problem

同一个请求头机密有两个操作面，而两者互相矛盾。详情弹窗给出的是**凭据配置区**：每个引用一条只写不读的 `SettingsSecretField`，带已配置徽标、保存与删除控件，以及一行说明哪个座位在用它。服务编辑器给出的是文档原文——`Authorization` 旁边一个普通输入框里躺着 `${CONTEXT7_API_KEY:-}`——于是"编辑这个服务"的弹窗没地方设置它需要的机密，而引用语法被当成了值来读。两者之所以不同，是因为它们本就是两样东西：文档里存着引用，机密存在宿主凭据库里，让它们看起来像同一件事的两种做法的，只是呈现方式。

**文档自带的字面机密读起来更糟。** 这类值根本到不了浏览器：线上被脱敏成 `[redacted]`，而编辑器把这个占位串当成可编辑字符串显示——用户读不到值、认不出它是机密，还可能把它原样存回去、覆盖掉真值。

**而且这个区块每个机密一整块字段。** 两个引用就是两组「标签 + 输入 + 说明」和四个按钮，把表单到高级设置之间的空间全占了。

## Decision

**这个区块是共享 UI，并且同时承载两类机密。** `McpCredentialFields` 位于 `src/client/ui/`，带三个助手：`credentialUsage`（哪个座位在用哪个引用）、`literalSeats`（哪些座位的值被线上脱敏）、`credentialRefOf`（一个值**是不是**恰好一个引用）。它接收入口数组——凭据库回答的引用，或文档自带的字面值——每个机密渲染成一条折叠的 `DetailRow`：一个服务带几个机密就只占几行，展开才是写入它的控件。详情弹窗与服务编辑器挂同一块；LSP 挂载路径解析的是插件路径而非凭据，因此它的编辑器不挂此区块，JSON 视图则展示整份文档。这一组的名字作为头部条带待在同一个框里：浮在边框外的标签会被读成下一个带框分组的标题——也就是紧随其后的高级设置。

**恰好是一个引用的值，读作它指名的凭据。** 请求头或环境变量里的 `${NAME}` 与 `${NAME:-}` 变成一枚 chip——盾牌图标加名字，原文做 tooltip——激活该 chip 会把这一行交回文本输入框，文档里没有任何东西变得够不到。

**被脱敏的值，读作一个隐藏的机密。** 值单元格里的占位串变成一枚静态 chip，写着已配置且已隐藏；值本身只经区块里那一行写入，在编辑器里就是写回文档——占位串原样返回时，保存路径会精确还原被遮住的叶子，因此原值得以保留。

**只有拥有文档的那一面才写字面值。** 编辑器的字面值一行带替换与删除控件，直接改座位；详情弹窗的那一行只点名座位，并说明去哪里替换。

## Alternatives considered

**凭据区留在详情弹窗，编辑器里的引用继续按文本显示。** 最省的改法，也正是这次报障的状态。否决：编辑器才是编辑这个服务的地方；为了设置这个服务需要的机密而把用户支到另一个弹窗去，这个问题本身就是不一致。

**把引用在输入框里美化一下。** `<input>` 只能渲染一个字符串：它承载不了图标、状态或第二个目标，所谓"好看"顶多是换个字色。

**把挂载会解析的每个座位都做成 chip。** 引用也可能出现在 `args`、`cwd` 或 URL 里。那些是单值字段，值通常是混合文本；在那里做 chip，要么盖住周围文字，要么在一个并非纯引用的值上误触发。两张映射表——请求头与环境变量——才是引用真正待的地方，也是这次做 chip 的两处。

**干脆把引用语法从表单里藏掉。** 看起来更干净，但文档才是权威：夺走回到原文的路，等于让表单对它正在编辑的东西说谎。

**继续把占位串当可编辑值。** 对线上数据诚实，对读者毫无用处：这个字符串不指向任何值，把它原样保存回去与"真想存这个字符串"无法区分。

**每个机密一整块字段，照宿主设置表单的写法。** 那种形态属于设置页；在一个已经带着表单的弹窗里按机密重复，会把弹窗其余内容顶出屏幕。折叠行把宿主字段保留在下一行里。

**让报告弹窗也能写字面值。** 那它就得拥有服务文档，而这正是本插件到处维持的分工：详情只报告，编辑器才编辑。

**把名字留在框外。** 那是详情弹窗其它分组的形态，也不用新增一行。否决：这些分组是层层堆叠的框，写在框外的名字会被读成下一个框的标题——也就是这次报的困惑：高级设置看起来像凭据的一部分。

**顺手提供"把字面值存成凭据"。** 把字面 token 变成 `${NAME}` 意味着起名字、写机密、改写文档并保持该座位的语义；那是一件独立的功能，仍然推迟。

## Consequences

- 一个服务的机密——引用的或字面的——在它出现的每一处都只占一行，两种都由编辑器写入：引用经凭据库，字面值经文档。
- 编辑器里的 chip 是按钮：键盘用户激活它即可到达引用的原文，或字面值的替换输入框。
- 表单未做 chip 的座位——URL 查询串、`cwd`、参数——里的引用仍按文本显示；被脱敏的**参数**仍按参数内部的文本显示。
- LSP 编辑器永远不显示该区块：它的挂载解析的是插件路径，不是凭据。
