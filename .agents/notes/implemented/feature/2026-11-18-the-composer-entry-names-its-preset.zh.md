# Agent Note: 输入框入口写出它选中的预设

Status: implemented

## Problem

输入框旁的预设入口原是一枚图标，含义只活在 tooltip 里。读者不悬停就分不清一个会话是跟随已保存的预设，还是跟随全局选择；而悬停恰恰是键盘读者难以随手做到的。它所在的那一行别处没有这个问题：权限芯片和模型芯片都写出自己当前的值，于是唯一决定会话带哪些扩展的控件，也成了这一行里唯一看不见状态的控件。

页头只放图标的那条规则管不到这个座位。[页头带图标](../architecture/2026-11-03-the-header-carries-icons.md) 管的是九个页面的页头与工具栏——那里每一项都是动作，一个被翻译的词会让共享页头在两种语言下宽高不同。输入框旁的芯片是选择器：宿主自己的权限与模型控件在那里就是文字芯片，理由相同，而这个入口属于同一族。

## Decision

- **入口在图标旁写出预设名。** 标签是所选预设的名称，会话不跟随任何预设时是全局那一个词，窗口尚未应答时是该读的状态词（`epNotReady`、`epLoading`、读取失败）。已在上改动的选择显示预设名；「已改动」后缀留在 tooltip 与可访问名里，因为它是第二个事实，而这一行还并排坐着两个控件。
- **芯片穿宿主自己的输入框芯片外壳。** 28px 高、`radius-sm`、13px/20px、字重 500、`label-secondary`、透明底配 `interactive-bg-hover` 悬停、图标 14px、箭头 12px——全部抄自它两侧的宿主控件：`InputBar` 的模型选择与 `PermissionSelect` 的触发器。它因此是一枚原生按钮：`Button` 原子的紧凑尺寸（12px、`label-primary`、10px 内边距）会把这些属性逐条覆盖，结果是一枚不再像邻居的芯片。
- **宽度设上限，不设固定值。** 标签在 220px 的控件内以省略号截断，和宿主的模型选择同一个上限，因此一个很长的预设名不会把权限与计划挤出这一行。完整名称留在 tooltip 与 `aria-label` 里。
- **座位仍是宿主 slot。** `conversation.input.left` 是这个入口原本所在、也是宿主渲染完自己的模式芯片之后的位置；名称画在这个入口内部，而不是再注册一个条目，因此每个会话该 slot 仍只有一个占用者，菜单也从同一个目标打开。

## Alternatives considered

- **保留图标，靠 tooltip 说明。** 否决：需要读的正是状态，而悬停不是阅读。需求是让当前预设立即可见，不是按需解释。
- **在图标旁另画一个 Tag 写名字。** 否决：触发器是一个打开菜单的控件；标签要么成为同一菜单的第二个点击目标，要么只是一段不干活、挨着干活控件的文字。
- **用共享的 `Button` 原子，把名称当子节点。** 读过两者后否决：原子的紧凑尺寸是 12px、`label-primary`，而这一行每枚芯片都是 13/20 中等、`label-secondary`。全部覆盖之后，留下的只是一枚挂着原子名字的按钮。
- **让入口随名称变宽。** 否决：输入框左侧组与权限、计划共享一行，一个长预设名会把用户没有碰过的控件挤走。
- **芯片里也写「已改动」。** 否决：它把标签长度翻倍，只为一个人已经在菜单与 tooltip 里读到的事实，而菜单里的勾选才是读者确认这件事的地方。

## Consequences

- 会话当前所处的预设无需交互即可读，空白会话的输入框与进行中的会话一致。
- 入口宽度随名称变化，最多 220px，之后截断；完整文本留在 tooltip 与可访问名里。
- `docs/user/settings.md` 与中文配对描述这枚芯片，不再是图标按钮。
- README 的演示录屏里是改动前的纯图标入口；差别是最后几幕中一个控件的宽度，等入口再次变形时重录。
- 只要设置开着，入口就渲染：已发布的 slot 契约会给每个 session 作用域的位置传入会话 id，所以[入口可见性修复](../bug-fix/2026-11-24-the-preset-entry-shows-and-its-suggestions-are-cards.zh.md)删掉了没有 id 时隐藏入口的那道守卫。

## Testing

`e2e/presets.spec.ts` 启动真实宿主，打开一个会话的输入框，读入口的可访问名（英文 locale 下为 `Default`），打开预设管理器，并驱动建议对话框唯一一次桩住的答案。`pnpm run check:quick` 与 `pnpm run test` 通过。

芯片已与宿主自己的权限、模型芯片对照：28px 高、同样的 13/20 中等次色文字、同样的箭头与悬停底色。
