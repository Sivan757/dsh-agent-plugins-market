# Agent Note：等宽源胶囊网格，悬停浮层展开

Status: implemented

## 问题

市场页头部把每个源渲染成一枚胶囊，装在会自动换行的网格里（`repeat(auto-fill, minmax(118px, 1fr))`）。注册 20 个源时，这条胶囊带长到六行（约 164px）；再叠加未登记仓库提示行与工具条间距，固定头部高度约 208px——而 `.header` 是 `flex-shrink: 0`，这笔开销全部由卡片区承担。同一批胶囊还为收编源带上了 `已收编` 徽标，把一个实现细节（`.sources/<id>` 目录被就地登记）说成了用户可见状态；同时首枚 `全部 754` 与同屏工具条里的 `全部 754` 重复。

## 决策

- **胶囊带仍是等宽网格。** `.sourceTabsRow` 保留 `repeat(auto-fill, minmax(118px, 1fr))`，同一行里每枚胶囊等宽，长 id 省略而不是把列撑开。承载方式是网格本身——不是下拉菜单，也不是横向滚动条。
- **网格折到两行，并用底部渐隐自我提示。** `.sourceTabsBoxFold` 预留 52px（两枚 24px 胶囊加 4px 间距）；网格以 `inset: -6px -6px auto` 脱离文档流，`max-height: 58px`（52px 内容加 6px 顶部内边距；折叠态不留底部内边距，否则会在工具条上方压出一条白带）加 `overflow: hidden` 裁剪，再用 `mask-image` 让最后一行渐隐。
- **悬停或键盘聚焦时，同一个网格以浮层展开。** `.sourceTabsBoxFold:hover .sourceTabsRow` 与 `.sourceTabsBoxFold:has(:focus-visible) .sourceTabsRow` 抬高 `max-height`、加上描边与投影并去掉遮罩，于是胶囊带盖在工具条和卡片之上展开，下方内容不发生任何回流。展开完全由 CSS 完成：没有开关控件、没有下拉、也不多占一行。聚焦那半用 `:focus-visible`，绝不用 `:focus-within`：鼠标点击会让被选中的胶囊保持聚焦，而普通聚焦会在点选抑制失效后自己把胶囊带重新撑开。
- **选中一个源后胶囊带立即折回。** 胶囊的选中回调会置起 `picked`，指针仍在带内时也保持折叠高度。清除它要等 `onMouseLeave` 之后 300ms（`LEAVE_GRACE_MS`）：折叠本身可能把指针扫出胶囊盒，没有这段宽限，下一次指针移动就会立刻重新展开。焦点离开胶囊带（`onBlur` 配合 `relatedTarget` 判断）则立即清除。
- **胶囊顺序为 `全部` → 选中的源 → 其余按 id。** 选中的源被移到 `全部` 之后，折叠状态下仍能看到当前筛选范围及其 `✎` 入口；其余胶囊保持 id 顺序。
- **选中胶囊使用 harness 主色。** `.srcTabOn` 底色用 `--dsw-alias-brand-primary`，文字用 `--dsw-alias-label-primary-foreground`——harness 的主按钮与开关 ON 态用的就是这一对（浅色近黑、深色近白）。此前试过的柔和业务底色（`state-business-tertiary`）已弃用：高亮应当读作 harness 的主色表面，而不是一块带色胶囊。
- **`SourceTabsRow` 只负责判断是否需要折叠。** 它把网格 `scrollHeight` 与折行高度（52px 加 6px 顶部内边距）比较——`scrollHeight` 在裁剪状态下仍上报完整内容高度，且浮层展开时不变，因此折叠状态在指针停留期间保持稳定。两行放得下时保持普通文档流网格，没有渐隐也没有浮层。
- **胶囊自己承担文字的左右内边距。** `.srcTab`/`.srcTabOn` 设 `padding: 0 10px`，`.srcTabMain` 不再自带内边距，所以无论有没有尾部的 `✎`/`×` 操作，文字左右两侧都保持同样的 10px 间距；这些操作只额外贡献 4px 的间距。
- **不再展示收编徽标。** 胶囊只保留 `本地` / `压缩包`；收编 checkout 只是管理器恰好拥有的存储，不是用户可选的状态。两份字典中的 `sourceAdopted` 已删除。
- **未登记提示靠处理目录来清除，而不是靠忽略。** `unmanagedSources()` 只列出 `.sources/` 下真实存在且未登记进 `state.json` 的目录，因此删除或收编后该行自行消失；「忽略」动作仍未实现。

## 已考虑的替代方案

- **单行 `+N` 溢出菜单** —— 先实现过，随后被否决：下拉把源藏在一次额外交互之后，而要求是留在页面上、等宽的胶囊。
- **两行加显式的「展开全部」/「收起」开关** —— 接着实现过，同样被否决：开关自己占一行，21 个源里只有 8 个可见，展开时还会把卡片区推下去。
- **单行横向滚动** —— 能保留全部胶囊，但在设置页头部做横向滚动比换行更糟，且被藏起来的胶囊与进菜单一样不可达。
- **内部纵向滚动（`max-height` + `overflow-y: auto`）** —— 已在 [workspace-tabs 笔记](2026-09-06-workspace-tabs-user-panels.zh.md)中因嵌套滚动条抖动被否决；在头部再引入一个会重演该问题。
- **只渲染前 N 枚胶囊来折叠** —— N 取决于响应式列数，需要逐枚测量；在行边界裁剪网格零成本，且不会把胶囊裁掉一半。
- **保留 `已收编` 徽标** —— 它只回答实现自己的问题，而且它暗示的删除语义此前被写错了。

## 影响

- 折叠态恒为 52px 且不带任何额外装饰；展开态盖在工具条与卡片之上，因此卡片区在任何状态下都不会移动。
- 浮层展开时会遮住工具条。这是刻意的——此时指针已经在胶囊带内——但意味着要点搜索框得先把指针移出胶囊带。
- 折线以下的源是被裁剪而非移除：它们仍留在 DOM 里，屏幕阅读器与键盘聚焦都能到达，聚焦任一胶囊即会展开浮层。
- 由于选中的源会被移到 `全部` 之后、点选后胶囊带又立即折回，折叠态始终能看到当前范围，其余列表不动；「范围已改变」的反馈同时来自工具条计数与被筛出的卡片。
- 两行放得下的源列表保持普通文档流网格，没有渐隐也没有浮层，短列表不为此付出代价。
- 本次同时修正了「已收编目录受删除保护」这一过时表述（README、使用指南、官网 FAQ、`removeSource` 的 JSDoc 以及两篇 Agent Note）：`removeSource(id, deleteCheckout)` 会删除 `.sources/<id>` 下的 checkout（包括已收编的），只有指向 `.sources/` 之外的 `local` 源受保护。
