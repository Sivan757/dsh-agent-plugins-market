# Agent Note: 详情页整篇翻译文档正文，分块进行，收在折叠区里

Status: implemented

## Problem

文档正文可能超过单次 provider 请求或模型输出预算。翻译失败或中断不能丢掉已完成的工作、损坏可运行的示例，或让原文无法阅读。

最初的阅读器把整篇译文放在第二层折叠区内。这一阅读模式决策由[三态阅读与翻译生命周期](2026-10-06-translation-reading-and-lifecycle.zh.md)取代。本记录仍拥有请求限额、正文角色与仅传身份的读取规则，不再规定当前阅读器布局。

## Decision

文档通过有上限的正文片段传输，而不是一次交给 provider。已完成的片段独立缓存。当前的 AST 分段与逐段对照由[替代决策](2026-10-06-translation-reading-and-lifecycle.zh.md)拥有，不沿用最初按空行贪心组块的策略。

### 一并约束输入与输出

本地化器同时限制每批的文本条数和源字符数。模型适配器按一次调用所带的源文本确定输出预算，并拒绝截断的输出。这些是应用侧预算，不是在声明厂商消费级端点未公开的限制；更换端点或增加目标语言时应一并复核。

描述也使用有上限的块。分块器保留源分隔符，因此未翻译的块可以重建原字段。自行插入空行可能把围栏示例移出列表项，或把紧凑列表改成松散列表。分块器不会为了填满块预算而合并独立段落。

### 保留角色槽

正文与描述共享面和实体 id。持久键包含角色 `description` 或 `document`；省略角色等同于 `description`，保留既有描述键。角色区分持久记录，而本地化器的内存文本索引可以跨角色复用同一答案。

### 服务端读取文件，页面只报身份

面板翻译路由接受条目名称，经 `PanelResourceStore` 解析文件。store 在翻译前剥掉 frontmatter：元数据属于概览，翻译 YAML 会破坏语法。路由不翻译调用方提交的正文。[市场路由决策](../architecture/2026-10-05-market-document-translation-route-and-identity.zh.md)把同一身份规则扩展到安装前预览。

## Alternatives considered

**每个源码块各用一个宿主 MarkdownText 渲染。** 不采用：跨块引用与脚注需要整篇上下文，每个容器首尾子元素的间距也会改变整篇节奏。当前阅读器仍渲染一份完整 Markdown；服务端 AST 变换不需要第二套客户端渲染器。

**像浏览器扩展一样向 React 已渲染的 DOM 插入节点。** 否决：这棵树由 React 拥有，外部节点不在其子节点顺序中，可能与后续渲染冲突。

**不解析 Markdown，只按空行切开后渲染。** 否决：松散列表、嵌套段落和围栏示例可能改变结构。描述的无损分块不能替代对待渲染文档的解析。

**整篇发送，让 provider 拒绝。** 否决：模型可能截断生成而不是拒绝；不能把部分答案当成完整译文。

**每条文本使用固定输出预算，只限制条数。** 否决：一条长文本与多条短描述需要不同的输出预算。源长度、批次限制和输出限制必须一起考虑。

**将翻译后的 Markdown 渲染成纯文本，或把代码随正文一起翻译。** 否决：纯文本丢失可读结构，翻译后的示例可能无法运行。宿主 Markdown 渲染器负责安全渲染，AST 变换让代码不进入 provider 输入。

**按位置给片段取键。** 否决：插入一段会让无关的相邻段落失效。稳定实体身份与片段文本能保留这些记录；改变分段方式仍可能留下不用的旧缓存，直到重置。

## Consequences

打开文档会请求其正文，而不只请求视口当前可见的段落。关闭阅读器会停止读取，已提交的工作仍可能完成。完成的结果可以复用。全局关闭与重置的保证由[生命周期决策](2026-10-06-translation-reading-and-lifecycle.zh.md)拥有。

译文视图覆盖去掉 frontmatter 的正文，可能规范化 Markdown 语法；原文视图保留作者文本。缓存按有上限的正文片段增加记录，而不是每个文件一条。
