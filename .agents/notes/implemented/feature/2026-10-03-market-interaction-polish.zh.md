# Agent Note: 日常用语与快速本地交互

Status: implemented

## Problem

技术化导航用语不便于浏览设置。专家模型表单用三行展示三个简短选项。插件技能开关写入调用控制，但列表只读取旧的 disabled 标记。加载反馈的最短展示时间与结束缓冲会在操作完成后继续阻挡用户。

## Decision

- 导航使用市场、技能、快捷指令、专家、连接器与代码智能。服务说明保留 MCP 和 LSP；操作系统命令保留技术名称。
- 专家新建与编辑共用 RoleMetadataFields。三个控件使用自适应网格，错误与当前模型摘要横跨整行。其他字段组保持不变。
- 插件技能列表通过共用技能解析器读取两个调用控制。快捷指令与专家保留既有 disabled 标记和开关。插件内容与删除仍受保护；专家保留仅模型配置编辑器。
- 加载反馈保留 200ms 显示阈值，不设置最短展示时间或结束缓冲。读取始终可交互，包括延迟提示可见期间。写操作仍立即防止重复输入；只有写操作反馈可见时才改变焦点与 inert 状态。最后一个操作租约释放时立即移除反馈，失败路径也相同。

加载决策部分取代[工作区面板](2026-09-06-workspace-tabs-user-panels.zh.md)，后者仍持有面板组织与文档存储决策。[仅模型配置编辑器](2026-09-26-persona-routing-editor.zh.md)继续持有插件文档权限规则。

## Alternatives considered

**保留最短展示时间。** 它能平滑短暂的加载图标，却强制用户在工作完成后继续等待。延迟显示可以过滤快操作，无需延长已完成工作。

**移除全部交互保护。** 这会允许重复写入，以及保存期间关闭窗口。现有租约保留写操作保护，读取则不立即阻挡。

**复制新建与编辑表单。** 两者已通过同一个组件修改相同 frontmatter，局部 CSS 网格足够。

**引入新的开关存储。** 既有可写插件文档已经持久化相关字段。独立覆盖存储还需要运行时与来源更新策略变化，超出本次修正。外部来源文件和内联 JSON 资源保留既有只读限制；来源刷新可能覆盖受管检出中的编辑。

## Consequences

没有新增依赖、路由或持久化设置。略超过阈值的请求仍可能短暂显示提示，但已完成的工作不会等待提示。虚拟时钟测试覆盖及时关闭、短读取、并发租约、错误与写保护。面板测试覆盖三类插件开关的停用、重新加载和启用，并保留正文编辑与删除限制。现有 GUI 验证需要已登录的浏览器会话。
