# Agent Note：每个面板页头一样高

Status: implemented

## Problem

设置页九个页签里有一个的工具栏高度和别人不同。实测：除 `系统提示词` 之外每个页签的工具栏都停在 y=158，而它是 y=162。它的页头是 28px，别人是 24px——因为这个页签的页头带一个文字按钮（新建），其余只带图标按钮，而「只有描述」的页头把 `min-height` 设成了 0，于是最高的子元素决定了行高，也决定了下面工具栏落在哪。

## Decision

- **紧凑页头设 28px 下限。** 那是一个页头能带的最高操作（小号文字按钮），于是带图标按钮的面板和带文字按钮的面板现在画出同样的页头高度、同样的工具栏行。这个下限只作用于「只有描述」的变体；带标题的页头仍保留 46px。

## Alternatives considered

- **把「新建」改成图标按钮。** 否决：创建动作打开的是一份候选菜单，需要一个词；为了 4 像素把它缩成图标，是用一个更差的交互换掉一处不一致。
- **让面板外壳自己量页头。** 否决：CSS 已经知道操作高度；为了四个像素在每次切页签时读一次布局不值得。

## Consequences

- 八个非市场页签的工具栏都画在 y=162；市场页签仍是 218，因为来源胶囊按设计在它上方。
- 将来若有高于 28px 的页头操作，会带着所有页签一起移动，而不是只动一个。

## Verification

- 在 `market-dev` 实测：九个页签读到 barTop 218（市场）与 162（其余八个），此前只有 `系统提示词` 是 162、其余是 158。
- 切换页签的回归测量仍然报告「无位移」。
- 四个类型检查、`check:refactor` 与全量测试通过。
