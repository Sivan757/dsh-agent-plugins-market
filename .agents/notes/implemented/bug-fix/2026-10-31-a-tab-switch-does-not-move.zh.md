# Agent Note：切换页签不再移动内容区

Status: implemented

## Problem

负责人反馈：除了市场、技能、专家三个页签，其它页签在切换时内容区都会抖动。在 `market-dev` 里逐帧实测，原因在两个面板，且是同一种失败：首次读取还在路上时，它们只渲染「页头 + 一行占位」，读取完成后再把工具栏与列表挂上去。

| 页签       | 首帧                   | 稳定后                     | 位移      |
| ---------- | ---------------------- | -------------------------- | --------- |
| 系统提示词 | 没有工具栏、没有列表盒 | 工具栏在 y=193，列表高 519 | 整块下移  |
| 输出风格   | 没有工具栏、没有列表盒 | 工具栏在 y=158，列表高 554 | 下移 50px |
| 其余七个   | 工具栏与列表盒已在     | 不变                       | 无        |

系统提示词那行作用域说明（「未指定会话，显示宿主进程工作目录下的链条」）还压在工具栏之上，于是这个页签的控件长期比其它页签低 35px。

## Decision

- **每个面板只有一棵树，与数据无关。** 输出风格与系统提示词不再返回「只有页头」的骨架：首帧就渲染页头、失败带与共享列表，条目为空、列表盒里写「加载中」。工具栏与列表盒在任何状态都在同一位置。
- **列表级说明放进列表盒。** `ResourceSurface` 新增 `notice` 槽，画在工具栏之下、集合之前。系统提示词把作用域说明放进去，于是八个非市场页签的工具栏都停在 158 这一行，而不是某一个在 193。
- **控件就是骨架。** 一个在其它页签上都有搜索框和视图切换的面板，加载时也要有它们——它们和页头一样，属于「你选中的是这个页签」。

## Alternatives considered

- **给加载态预留固定高度。** 否决：只修数字不修原因；工具栏迟到仍会把控件闪进来。
- **缓存每个界面的首次读取，让它永远不加载。** 否决：把缺陷藏在热缓存后面，第一次打开仍然会跳。
- **把作用域说明塞进页头副标题。** 否决：同样把工具栏推低 35px，而且副标题有 20 字预算。

## Consequences

- 每个页签的工具栏同一行，列表盒同一起点。
- 切换页签只换列表内容，其上的一切不动。
- 新面板只要首帧就渲染 `ResourceSurface`，就继承这个形状。

## Verification

- 在 `market-dev` 对九个页签实测，在 0/12/24/36ms 与 450ms 采样工具栏与列表盒：现在每个页签都报告「无位移」，八个非市场页签共享 y=158 的工具栏与 554px 的列表盒。
- `packages/market-ui/test/client-output-styles-panel.test.ts` 与 `client-instructions-panel.test.ts` 在「首次读取永不返回」时钉住工具栏与列表盒的存在。
- 四个类型检查、`check:refactor` 与全量测试通过。
