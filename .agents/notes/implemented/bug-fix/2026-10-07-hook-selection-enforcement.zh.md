# Agent Note: Hook 授权遵循每项已发布的选择

Status: implemented

## Problem

预设管理器提供用户和项目 Hook 的独立开关。仅检查父级授权会执行会话未选择的 Hook。

## Decision

资源清单、投影和运行时共享由事件与位置组成的标识。位置对同一事件的所有匹配分组中的命令 Hook 连续计数。

只要选中任意独立 Hook，投影就保留原始声明。运行时在派发前同时检查套件和独立标识。不压缩声明数组，以免改变后续标识。

已安装市场套件在会话资源清单中没有独立 Hook 行，其 Hooks 保留父套件选择契约。用户和项目 Hooks 则要求逐项选择。

## Alternatives considered

派发前过滤命令数组。否决，因为压缩后的数组会重排剩余 Hooks，使其与已保存选择不一致。

要求所有已安装套件逐项选择。暂缓，因为这些套件的已有预设仅包含父级标识。该改动需要同步资源清单与迁移方案。

替换宿主协议。否决，因为已发布协议已经负责 shell 执行、输出解码和生命周期记录。插件只补充选择授权。

## Consequences

可见的 Hook 开关控制实际执行，无需修改宿主。声明位置仍使用现有身份格式，不改为内容哈希。

路由级回归保留已安装套件的正向用例，并检查用户 Hook 的负向用例。运行时测试覆盖匹配分组和越界标识。

[隔离验收报告](../../../../docs/reference/version-repair-2026-10-07.md)记录浏览器选择、实际 shell 标记与重启证据。
