# Agent Note: 刷新输入框技能并保留详情内容流

Status: implemented

## Problem

扩展选择会使服务端注册表失效，但已发布的输入框在原生预设事件或重连前缓存技能列表。重新打开菜单仍可能显示已移除技能并遗漏新技能。详情弹窗也把 flex 规则应用到每个内容子项，拉伸无关章节并改变行方向。

## Decision

适配现有技能来源。候选查询读取已发布的 skills/list 接口，按会话保留词表和预览快照。保留宿主排序和选择行为。新列表完成后显式刷新公共菜单控制器。存在词表订阅者不代表存在菜单订阅者。

通过公共 SessionBinding 事件源观察已提交扩展信封。窗口读取在采样就绪状态和版本前等待当前选择写入完成，不等待活跃用户轮次。繁忙意图在执行边界前仍不授予能力。

由唯一 DetailModal 内容栈负责 flex 分配和容器查询。不对调用者的每个内容块设置纵向布局或弹性增长。固定设置框、页脚槽位和共享详情组件保持不变。有效保存前清除本地校验，让旧名称错误不再遮住当前服务端失败。

## Alternatives considered

加快轮询不能清除宿主技能缓存。连接重置或伪造原生预设事件会影响无关宿主状态。已发布技能客户端没有公开失效方法，因此用有限范围的来源适配器替换其目录相关方法，不增加注册表或菜单。

宿主负责技能 RPC、排序、输入触发器、会话事件订阅和资源预览地址。复用这些接口。workspace-path 工具没有浏览器模块工厂，因此客户端打包其纯实现，而不是从宿主模块表请求。

模型轮次运行时更改技能执行违反已确认的轮次契约。即时发现刷新仅跟随已提交状态。现有选择队列提供发布屏障，不增加计时器或等待者注册表。

逐功能修改高度会保留造成缺陷的宽泛选择器。共享内容栈消除根因，并保留各详情自身的行与章节布局。

## Consequences

候选查询进行实时本地 RPC 读取。缓存快照支持引用样式与预览，不负责授权。过期响应、已释放作用域和旧服务实例不能发布新视图。宿主提供目录失效接口后，可移除此兼容适配器。

本决策细化[共享资源界面与下一轮选择](../architecture/2026-10-08-shared-surfaces-and-next-turn-selection.zh.md)，不替代其授权或持久事务模型。[验收报告](../../../../docs/reference/skill-refresh-and-detail-audit-2026-10-09.md)区分真实后端证据与受控浏览器状态。
