# Agent Note：这个页签是系统提示词，不是「规则」

Status: implemented

## Problem

列出 `AGENTS.md` 文件的那个设置页签曾按一次信息架构复盘改名为「规则 / Rules」，理由是已有三份用户文档在用这个词。负责人纠正了前提：这些文件是注入到 Agent 的**系统提示词**里的，所以「规则」命名的是一个产品并不存在的机制——错的是文档，不是页签。

## Decision

- **页签叫「系统提示词 / System prompt」。** 副标题说明它是什么而不是它叫什么：AGENTS.md 注入系统提示词。
- **页面内文案跟随页签**：「系统提示词页面不可用」「读取提示词链失败」，取代此前的「规则」措辞。
- **文档一起搬家。** 用户页标题改为「系统提示词 / System prompt」，首段说明这些文件被注入到会话的系统提示词；两份 README 表格同步改名。
- **专家编辑器保留「角色指令」。** 它在同一轮里被从「系统提示词」改走，这一部分仍然成立：角色文档不是提示词。

## Alternatives considered

- **保留「规则」、改文档。** 负责人已否决：这个界面确实是系统提示词，让文档叫它「规则」等于描述一个不存在的产品。
- **页签叫「提示词」。** 否决：更短，但读起来像泛指的「提示词」，而这个界面特指会话收到的系统提示词。
- **专家字段仍叫「系统提示词」。** 否决：两个不同对象会再次共用一个说法，正是这一轮要消除的歧义。

## Consequences

- 知道系统提示词是什么的读者，能用它真正的名字找到这一页。
- 早前记录「规则」命名的两条笔记被标注为部分被取代，并双向交叉链接。
