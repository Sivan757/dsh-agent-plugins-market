# Agent Note：来源胶囊把控件遮在自己的名字上

Status: implemented

## Problem

胶囊末尾的控件被重做成「名字永远不会压在它们下面」，代价是控件打开时胶囊会变宽：控件在胶囊内部占位，于是悬停一颗胶囊就宽出控件的宽度，把它后面的每一颗都沿着来源条挤开。老板看过运行中的应用，要求恢复发布版的形式——控件作为一整块板盖在胶囊的尾缘，用内部遮罩（不透明的板加一圈羽化边缘的扩散阴影），悬停时显形，而胶囊恰好和它的名字一样宽。

但发布版的形式有一个缺陷，不能跟着一起回来。发布版的样式里板不吃点击，而它的按钮吃：`opacity: 0` 不会取消命中测试，于是看不见的编辑与删除按钮是压在名字上的活靶子。本想点名字的那一下落在控件上，而那个看不见的删除按钮离「移除来源」的确认只差一次点击。

## Decision

- **板就是发布版的那块板。** `.srcTabControls` 绝对定位盖在胶囊尾缘（`position: absolute; top: 0; right: 0; height: 100%`），用内部遮罩绘制——`background: inherit` 加 `box-shadow: 0 0 6px 6px var(--dsw-alias-bg-layer-1)`——悬停或键盘聚焦时显形（绝不用普通的 `:focus-within`，否则鼠标点击留下的普通焦点会把板钉在读者刚点过的那颗胶囊上）。运行中的应用里它宽 51px。
- **几何就是发布版的几何。** 胶囊和它的名字一样宽，同一个 220px 上限，也不为控件预留任何空间：板不在流内，所以板打开时胶囊的尺寸不变。
- **看不见的控件是惰性的。** 板仍然 `pointer-events: none`，按钮在板打开之前也是 `pointer-events: none`，打开时才把指针事件还给按钮。收起状态的控件永远抢不走本该给名字的点击。
- **整颗胶囊都是选来源的靶子。** 胶囊的根节点带着选中处理，名字按钮阻止冒泡，于是来源恰好被选中一次，名字也仍然是给键盘和辅助技术用的真控件。
- **胶囊仍然用读者认得的名字称呼来源。** 那条决策记在[限定来源名](../feature/2026-11-05-qualified-source-name.zh.md)里；这次改动保留它，不在此重述。

## Supersession

这构成对[来源胶囊把名字留在自己的控件之外](../bug-fix/2026-11-05-the-source-chip-keeps-its-name-clear.zh.md)的取代：它的决策——控件在胶囊内部占位、打开时胶囊变宽——被发布版的板和发布版的几何替换。那条记录的其他事实依然成立：胶囊根节点负责选中、名字按钮阻止冒泡、限定名领在胶囊前面。

它同时**部分**取代[胶囊按 id 宽度排布](../feature/2026-10-30-source-chips-hug-their-ids.zh.md)：胶囊又是多宽的标签就多宽、同一个 220px 上限，那条记录的承诺完整恢复，来源条也回到从前每行能放那么多来源的状态。

## Alternatives considered

- **为板预留余量（放在标签的内边距里，或放在胶囊的尾部内边距里）。** 否决：老板在运行的应用里看过，要求发布版的密度——预留余量的胶囊比它的名字宽，来源条每行能放的来源更少。而且名字如今带上了上级目录，需要余量救援的短 id 已经少了。
- **保留变宽。** 否决：老板要求发布版的形式，而读者一指就变宽的胶囊会把它后面的每一颗都沿着来源条挤开。
- **把不透明遮罩换成半透明的veil，让名字透出来。** 否决：两个图形字仍然压在名字上，点击仍然落在控件上。
- **量出名字长度，只在板会吞掉名字时才预留余量。** 否决：每颗胶囊一个 ResizeObserver，宽度在首帧之后还会变，一条来源条里出现两种胶囊形状。
- **把板做窄。** 否决：板的宽度就是遮罩的样子，而且再窄也窄不过那两个图形字。
- **把控件挂到胶囊外面。** 否决：它们会盖住下一颗胶囊，并吃掉它的点击。

## Consequences

- 板打开时盖住名字的尾缘，这就是这种形式的代价：最短的那颗胶囊上只有名字开头的几个字符还看得见——54px 的名字里剩 13px——指针一离开，名字就回来了。
- 板没盖到的那部分名字仍然可选：点那里落在名字上，永远不会落在控件上，也不会弹出确认框。
- 胶囊又和自己的名字一样宽，来源条回到从前每行能放的数量：19 颗胶囊占 6 行。
- 控件不可见时仍然是惰性的，所以看不见的控件永远抢不走点击。

## Verification

- 在 `market-demo` profile（link 本仓库、用构建出的客户端包）实测：
  - 最短的胶囊 `ponytail 1`：胶囊 76px，名字 54px 的字迹，板 51px；板盖住名字的 41px，剩下 13px 可见；
  - 最长的胶囊 `claude-code-plugins-plus-skills 438`：胶囊 229px，名字 207px 的字迹，板盖住 41px，剩下 166px 可见；来源条里没有哪颗胶囊被省略；
  - 胶囊静置时 76px，悬停时仍 76px——尺寸不变；
  - 收起时板和两个按钮都是 `pointer-events: none`；悬停时板不透明，按钮是 `pointer-events: auto`；
  - 点名字没被盖住的那部分会选中来源（胶囊移到 `全部来源` 旁边并变成选中态），也不会弹出确认框，所以这一下永远到不了删除控件。
- `packages/market-ui/test/source-chip-legibility.test.ts` 钉住样式表的约定（板是发布版的那块遮罩板、按钮在打开前惰性、显形用 `:focus-visible` 且绝不用 `:focus-within`，以及胶囊不预留任何空间：没有任何规则给带控件的胶囊单独的尾部内边距、基础规则仍是 `padding: 0 10px`、标签也没有自己的 padding-right）与 DOM 的约定（名字不在控件里面、点名字只选中一次、点胶囊自己的区域也选中、点控件不会选中来源）。
