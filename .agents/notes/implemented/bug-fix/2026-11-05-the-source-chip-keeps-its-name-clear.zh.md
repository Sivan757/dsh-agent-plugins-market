# Agent Note：来源胶囊把名字留在自己的控件之外

Status: implemented

## Problem

市场页的来源胶囊把末尾的 `✎`/`×` 控件做成一块盖在名字上的板：`.srcTabControls` 绝对定位在胶囊右缘，不透明底加一圈扩散阴影，而它的按钮带着 `pointer-events: auto`，板本身却不吃点击。由此有两个缺陷，都在短来源名上暴露。

- 板和两个按钮一样宽，名字一短，整颗胶囊都被盖住：来源名被一块不透明矩形盖掉，读者分不清哪个来源是哪个。
- 板不可见时按钮照样是点击目标——`opacity: 0` 不会取消命中测试。悬停之后点击胶囊，落点是一个看不见的编辑或删除控件，而不是选中来源；那个看不见的删除按钮离「移除来源」的确认只差一次点击。

名字当时还是来源 id 本身：以短 id 存放的纯 skills 集合，说不出自己来自哪个仓库。

## Decision

- **控件是胶囊自己的最后一项，不是盖在名字上的板。** `.srcTabControls` 是胶囊的 flex 项（`flex: 0 0 auto`），名字永远不会被盖住，点它永远是在选来源。控件停在胶囊的尾缘，也就是卡片操作簇所在的位置。
- **收起时控件一点宽度都不占。** 这块板是 `max-width: 0` 加 `overflow: hidden`，于是静置的胶囊恰好和它的名字一样宽——[胶囊按 id 宽度排布那条记录](../feature/2026-10-30-source-chips-hug-their-ids.zh.md)的承诺保住了——收起的按钮既不画出来也不吃点击。
- **打开是让出宽度，不是盖上去。** 悬停（或 `:focus-visible`，绝不是普通的 `:focus-within`）把板的上限抬起来：有余量的胶囊按控件的宽度变宽，名字一个像素都不少；已经顶到 220px 上限的胶囊，把名字恰好让出旧板盖住的那一段宽度。读者读到的名字长度没有变。
- **看不见的控件永远不抢点击。** `.srcTabControls > button` 在板打开之前是 `pointer-events: none`，打开时才把指针事件还给按钮。板本身仍然不吃点击，所以胶囊自己的留白也是选来源。
- **整颗胶囊都是选来源的靶子。** `SourceTab` 的根节点带着选中处理，名字按钮阻止冒泡，于是来源只被选中一次。名字仍然是给键盘和辅助技术用的真按钮。
- **胶囊用读者认得的名字称呼来源。** 标签是 `source.displayName ?? source.id` 再加套件数；id 仍然是胶囊的键，也是它选中的范围。

## Supersession

这条记录已被[来源胶囊用自带的余量遮住自己的控件](2026-11-06-the-source-chip-masks-its-controls-over-its-own-room.zh.md)取代：控件又是发布版的那块板，盖在胶囊尾缘、用内部遮罩，胶囊不再因它们打开而变宽。名字离控件的远法换了——标签为控件预留所需的空间——而看不见的控件在板打开之前保持惰性，这也是这条记录本来就要求的。下面的决策原样保留。

## Alternatives considered

- **在静置时就为控件预留宽度。** 否决：每个来源的静置胶囊都会宽出控件的宽度，这破坏了[胶囊按 id 宽度排布那条记录](../feature/2026-10-30-source-chips-hug-their-ids.zh.md)的承诺，而且同样两行里能放的来源更少。
- **保留盖在名字上的板，只把它的指针事件闸住。** 否决：那只修好看不见的点击，修不好被盖住的名字——名字一短，板照样盖住整段标签，按钮照样压在它上面。
- **让名字在板下面收缩。** 否决：名字正是读者挑来源的依据；为了给控件腾地方而截断它，是拿更糟的缺陷换掉原来的缺陷。
- **把控件挂到胶囊外面、伸进来源条的间隙里。** 否决：它们会盖住下一个胶囊，并且吃掉它的点击。
- **在 JavaScript 里量名字、按测量结果切换布局。** 否决：每颗胶囊一个 ResizeObserver，只为决定一件 CSS 自己就能表达的事，而且 jsdom 测不了。
- **给控件在名字下面单开一行。** 否决：胶囊只有 24px 高，来源条又折叠成固定高度，多一行就改了折叠。

## Consequences

- 短来源名在控件打开时依然可读，点它就是选来源。
- 名字比控件还短的胶囊，在控件打开时按控件宽度变宽，控件收起时回到静置宽度；顶到 220px 上限的胶囊不动：名字让出的恰好是旧板盖住的那一段。
- 键盘够控件的方式不变：Tab 到其中一个控件会通过 `:focus-visible` 把板打开，按钮的可访问名也保持原样。
- 胶囊上现在是来源的限定名，所以只有短后缀不同的两个来源读得开。

## Verification

- `packages/market-ui/test/source-chip-legibility.test.ts` 钉住样式表的约定（控件是 flex 项、收起时不占宽度也不吃点击、打开是让出宽度、显形用 `:focus-visible` 且绝不用 `:focus-within`）与 DOM 的约定（名字不在控件里面、点名字只选中一次、点胶囊自己的区域也选中、点控件不会选中来源）。
- `packages/market-ui/test/market-section-render.test.ts` 钉住胶囊上的限定名。
- 宽度本身在 jsdom 里量不出来：上面的说法是从规则读出来的，不是从渲染出来的画面读出来的。
