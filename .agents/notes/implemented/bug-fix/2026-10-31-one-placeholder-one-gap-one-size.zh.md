# Agent Note：一个占位、一个间距、一个角色一个字号

Status: implemented

## Problem

对设置界面背后二十个样式表做间距审计，发现同一个角色在每个需要它的界面里都被画成不同样子，还有一条重构后遗留的死规则。

- **四个空占位。** 共享列表的 `.empty` 是 16px、左对齐；系统提示词与输出风格是 24px 居中；市场的错误兜底是 48px、13px。空页签和空列表看起来像两个产品。
- **钩子摘要框漂移了。** 钩子详情用 14px/18px、12px 圆角、8px 标签间距，而市场与连接器详情画的是同一个框：12px/14px、10px 圆角、7px 间距。
- **同一行有两个间距。** 窄容器网格设 4px 卡片间距，注释还写着「一种节奏，不是两种」，而列表分支在所有宽度都保持 6px：切换视图时卡片间距会变 2px。
- **包内唯一的 10px 字号。** 连接器工具表有六条规则是 10px，而同样的次要文字在别处都是 11px。
- **一个不在共享节奏里的区块标题。** 输出风格预览标题是 12px、句子式大小写、上外边距，而其它详情区块都用共享的 block head（11px、大写、下外边距）。
- **一条死掉的标题规则**在切到共享标题后留了下来。

## Decision

- **空占位归面板所有。** `panel.module.css .empty`（24px 12px、居中、12px）就是「没有内容」时渲染的东西，共享列表自己的 `.empty` 取值相同。系统提示词、输出风格、市场与套件详情的副本删除，各自的本地规则也删掉。
- **一个摘要框、一个标签间距。** 钩子详情改为 12px/14px、10px 圆角、7px 标签间距，与市场、连接器详情一致。
- **两种视图一个卡片间距。** 4px，即窄网格注释里早就写下的值。
- **次要文字用 11px。** 连接器那六条规则上调。
- **输出风格预览标题改用共享 block head**，替换自带规则，并把本地规则删掉。

## Alternatives considered

- **把所有数值收敛成一套 token。** 暂时否决：宿主不定义间距/字号 token（它的设计平台是 383 条颜色声明），本地再建一套等于这个插件自己发明没人遵循的标度。命名共享类才是真正去掉副本的那一步。
- **保留市场 48px 的错误兜底。** 否决：错误行和空行是同一个占位，错误的颜色已经由消息本身承担。
- **因为工具表更密就保留 10px。** 否决：10px 低于所有其它次要文字，而这张表在 11px 下仍有空间。

## Consequences

- 空页签与空列表现在长得一样，且由同一个类决定。
- 钩子详情的摘要框与另外两个详情一致。
- 切换网格/列表不再改变纵向节奏。
- 四条本地规则与一条死标题规则消失；占位只剩一个文件里的一条规则。

## Verification

- 重建后在 `market-dev` 实测：空占位渲染为 `24px 12px`、居中、12px、高 65px；集合间距在网格视图为 4px，切到列表视图后仍是 4px。
- `pnpm run check:css` 仍是每个类都被引用或已登记；四个类型检查、受影响的界面测试与全量测试通过。
